01 / The idea

Share the rule.
Specialize the updates.

A single task moves through reaching, contact, transport, and precise placement. Its perceptual and control demands change along the way.

MorphAct learns one shared adaptation rule that maps the current observation, instruction, and robot state to context-dependent parameter updates. The policy adapts as the scene changes, without operation labels or separate expert policies.

Y^t=πθ+Δθ(xt)(xt)

xt = (ot, ℓ, st) is the current context; Δθ(xt) is its generated update; Ŷt is the predicted action chunk.

02 / Method

Perception shapes
the action update.

Two generators produce low-rank updates for the vision–language and action modules. Their connection follows the policy’s computation.

The VLM generator first adapts the representation. The action generator then uses the adapted features and robot state to generate its update, while the action predictor retains its native conditioning and solver inputs.

01

Generate for the context

Queries identify layers, projections, and rank positions. Token-level context conditions the generated A/B factors.

02

Learn the two generators jointly

The native action loss trains both generators through adapted action conditioning and action-side parameter generation.

03

Reuse within the chunk

Generate once per observation. Cache the updates and native action condition for every solver evaluation; refresh when replanning.

ΔWj,t=αjrjAj,tBj,t

For block j, A: din × r and B: r × dout. The base weights stay frozen; the low-rank factors change with the context.

Training objective and factored execution +

Apply the factors directly

y=uWbase+αjrj(uAj,t)Bj,t

The row-vector projection uses a factored residual, without materializing a dense update. Factor layouts follow each backbone’s projection geometry.

Retain the native action objective

minΦ𝔼(xt,Yt)∼𝒟,ξ[ℒnative(y^Φ(xt,Yt;ξ),Yt;ξ)]

Φ includes both generators, the state projection, and projectors retained as trainable by the adaptation configuration. ξ is the randomness used by the native objective.

For π0 and π0.5, training samples a time τ and predicts the velocity on the action–noise path:

zτ=τε+(1−τ)Ytvtarget=ε−Yt

The action generator uses final adapted multimodal tokens and robot state. Layer-wise prefix key–value states provide native action conditioning. Noisy actions and solver time remain in the native action path.

04 / Ablations

What makes
contextual adaptation work?

Six X-VLA variants on all four LIBERO suites isolate the generation condition, module coverage, and representation coupling.

A / Generation condition

Beyond task identity

+8.95%

Current-context generation reaches 97.20% mean success, versus 88.25% for Task-ID and 87.50% for Constant.

B / Module coverage

Adapt both modules

97.20%

The complete model exceeds either single-module variant: Action-only reaches 81.00%; VLM-only reaches 43.50%.

C / Feature coupling

Use adapted features

+11.20%

Conditioning action-side generation on adapted VLM features improves mean success from 86.00% to 97.20%.
